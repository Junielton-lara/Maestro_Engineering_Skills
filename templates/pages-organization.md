# Template — organização de páginas

- Uma feature = pasta `features/<domínio>/`
- Rota registrada no router central
- Página: header + dados + estados (loading/empty/error)
- Lista: cards no mobile; tabela no desktop (`lg+`) se necessário
- Form longo: página + action bar; form curto: modal/sheet
- Abas: querystring se compartilháveis
